## What is this project about?
This is the front end of the project (*Job Hunter*)[https://github.com/Clara690/job_hunter],whcih can be found on my repository 🙂

The interface provides a web page where job seekers can look for job postings from two major Taiwanese job serach platforms, [104](https://www.104.com.tw/) and [Cake](https://www.cake.me/jobs/data%20engineers?seniority_levels=entry_level%2Cassociate).

### Run the project locally 
```text
npm run dev
```
